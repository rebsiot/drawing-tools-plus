# Drawing Tools+ v0.1.12 — Select Several Drawings

## Fixed
- **Multi-select now works from All Drawings.** Click **Select** on one Drawing, then Select on another. The first one remains selected.
- **Select becomes Deselect** for each selected row. Clicking Deselect removes only that Drawing from the current selection.
- **Main Unselect** still clears the whole selection without changing or deleting artwork.

## How to use
1. Expand **All Drawings** and click **Select** next to two or more unlocked Drawings.
2. Choose a Quick Style or adjust the appearance controls, then click **Apply to N Selected**.
3. Click an individual **Deselect** to remove that one, or the main **Unselect** to clear everything.

## Safe by design
- Uses Foundry v14's native controlled Drawing list, not a new selection layer or separate data.
- GM/locked/hidden and other-player ownership protections remain in force; players can only select and modify their own unlocked Drawings.
- Clicking Select/Deselect never modifies, deletes, imports, or duplicates Scene Drawing documents.
- **Beta:** Automated and mocked tests passed; live Foundry v14 selection and styling regression tests are pending.
