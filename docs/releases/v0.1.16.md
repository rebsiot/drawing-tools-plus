# Drawing Tools+ v0.1.16 — Line, Route, Callout, and Clearer Chevron Ends

## New
- **Second row of tools:** Line, Arrow, Route, Callout. The original six tools remain in the first row.
- **Line:** Drag from start to finish. It becomes one native Drawing.
- **Route:** Click several waypoint positions; double-click, press Enter or click **Finish Route** to save. Right-click or Esc abandons an unfinished route. It becomes one editable native polygon Drawing.
- **Callout:** Drag from the point of interest to the label position. Enter a label to save a pointer and editable text label as two native Drawings. Each can be moved/edited separately.

## Fixed
- **Chevron arrowheads:** The previous Chevron looked almost the same as a filled triangle. New Chevron heads now have a pronounced V-notch. No unsupported freehand Drawing shape is used, and existing arrows are not modified.
- **All Drawings (0):** The heading now reads the actual Scene count as soon as the Quickbar opens, even when the list has never been expanded. Counts continue updating on Drawing creation or deletion.

## Compatibility and safety
- Foundry v14 native Drawings only. No scene conversion, mass import, changes to existing Drawing IDs, author permissions, flags, protected gridlines, or module ID.
- Arrow and route thickness is fixed when created because each is saved as one native polygon ribbon; native move/resize controls still work.
- Callout pointer and label are two independent documents, not an automatically synchronized group.
- **Beta:** Node/mock/static tests and ZIP packaging run in GitHub Actions. The new interactive tools, live Foundry rendering and immediate count still require testing in a real Foundry v14 world.

Back up your world before upgrading. To roll back module code use [v0.1.15](https://github.com/rebsiot/drawing-tools-plus/releases/tag/v0.1.15). Restoring an earlier module version will not restore deleted or overwritten world artwork.
