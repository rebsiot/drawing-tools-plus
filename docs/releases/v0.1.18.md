# Drawing Tools+ v0.1.18 — Multi-Delete (Public Beta)

**Status:** Public GitHub beta release with a complete installable ZIP and stable Foundry update manifest. Automated/mock-tested; **Multi-Delete has not been tested in a live Foundry v14 session**. Use a backed-up expendable Scene first.

## New
- **Delete N Selected** appears beneath the other selected-Drawing actions when at least two Drawings are selected. It is enabled only when at least two selected Drawings can be deleted.
- The native Foundry confirmation displays the exact eligible Drawing names, types and document IDs and identifies selected locked/unauthorized items that will remain.
- Cancel/closing the confirmation deletes nothing. Approval triggers one native Drawing deletion request containing only the listed eligible IDs.

## Safety and compatibility
- Recheck the Scene, original selected objects, document identities, locks, authors and delete permissions immediately before committing. Abort if anything relevant changed.
- Players may delete only their own unlocked native Drawings with Foundry's permission; locked artwork stays protected even from bulk deletion by the GM until explicitly unlocked.
- Deselect remains non-destructive. Per-object Delete still confirms separately. Undo Style Change cannot recover deletion. No migration or modification of existing Drawings during installation.
- All v0.1.17 controls, including Locate, native drawing tools, stable selection, Token Controls return, and style controls are retained.

## Install
1. Back up the world and existing `Z:\Data\modules\foundry-drawing-quickbar\` module folder.
2. Stop Foundry VTT. Extract the ZIP *contents* into that module folder, with `module.json` at its root.
3. Restart Foundry, verify module version 0.1.18, enable in your test world if necessary and hard-refresh the browser.
4. In a disposable Scene select three unlocked Drawings, cancel once, then confirm Multi-Delete. Verify only the listed targets disappear; check locked gridlines and player permissions separately.

## Rollback
Replace module files with the backed-up v0.1.17 folder or install the prior published [v0.1.17](https://github.com/rebsiot/drawing-tools-plus/releases/tag/v0.1.17) ZIP. Rolling back code **cannot restore** Drawings already deleted; restore the matching world snapshot for that.

## Testing
Node syntax/unit/mock and full ZIP integrity tests: see `docs/TEST-REPORT.md`. **Live Foundry v14 Multi-Delete: NOT TESTED.** The permanent GitHub manifest advances to v0.1.18 after publication of the matching version-pinned ZIP. v0.1.17 is the rollback release.
