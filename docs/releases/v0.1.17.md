# Drawing Tools+ v0.1.17 — Return to Token Controls

## Fixed
- Closing the Quickbar while using native Drawing Controls returns to Token Controls.
- Compact **Tokens** header button returns to native token movement without closing the Quickbar.
- Esc/right-click cancellation of unfinished custom annotations or new Text placement returns to Tokens without saving partial Drawings.
- Canceling an Edit Text dialog for an existing Drawing preserves the editing context.

## Preserved
- Completed shapes remain selected for immediate move/resize/style; switch to Tokens explicitly when finished.
- Native Drawing IDs, permissions, locked map artwork, author ownership, undo, selection and quick styles are unchanged.
- No automatic migrations or existing Drawing edits.

## Install / rollback
Back up the world. Install the ZIP in Foundry Setup with the permanent update manifest once the main manifest advances, or stop Foundry and extract contents into `Z:\Data\modules\foundry-drawing-quickbar\`. Restart and hard-refresh. If needed, reinstall [v0.1.16](https://github.com/rebsiot/drawing-tools-plus/releases/tag/v0.1.16). Reverting module code cannot undo changes to Scene Drawings.
