# Drawing Tools+ v0.1.8 — Clearer Deletion and Arrows

## Changed
- **Deselect** replaces the misleading "Remove" label. Deselect only stops selecting a Drawing; it never deletes it.
- **Undo Style Change** replaces "Revert Style". It restores the last Quickbar appearance change, not movement, labels or deletions.

## New
- **Delete:** A separate action for one unlocked Drawing, with a confirmation showing the name and ID. Locked Drawings remain protected.
- **Arrow ends:** Choose End only, Start only, Both, or No arrowheads before drawing. Each arrow remains one native polygon.

## Fixed
- Applying an appearance preset to a Quickbar arrow now preserves its filled silhouette rather than making it nearly invisible.
- Selected arrows retain their original polygon geometry; choose thickness before drawing, or resize natively.

## Testing and safety
- Automated checks and ZIP packaging passed; **these changes still require a live Foundry v14 test**.
- Back up your world before testing Delete. [v0.1.7](https://github.com/rebsiot/drawing-tools-plus/releases/tag/v0.1.7) is available to reinstall, but an earlier module version cannot resurrect deleted Scene artwork.
