# Drawing Tools+ v0.1.14 — Multi-Select Without Jumping

## Fixed
- **All Drawings stays put.** The entire Selected Drawings box—count, actions, and selected-object list—now appears **below All Drawings**. Adding a selected item cannot push the other Select buttons down.
- **Select/Deselect updates in place.** Each row keeps its existing button and its scroll position; only the text, selected highlight and accessibility state change. The list no longer rebuilds every time selection changes.
- **Stable button width.** Select and Deselect use the same minimum width so nearby controls don't slide sideways.

## Preserved
- Native multi-selection, the highlighted row, and the Selected Drawings list/count.
- Locked only filter, search, GM Locate/Unlock/Info, and native player ownership checks.
- No changes to any Scene Drawing, lock flags, geometry, IDs, or permissions during selection.

## Test and safety
- Back up the world first. Open **All Drawings** and select five temporary shapes in sequence. The list must stay fixed while the Selected Drawings panel beneath it grows; clicking Deselect on any row must leave the others controlled.
- Automated and mock regression tests/ZIP packaging run in GitHub Actions. **The new UI still needs a live Foundry v14 check.**
- [v0.1.13](https://github.com/rebsiot/drawing-tools-plus/releases/tag/v0.1.13) remains available for module rollback. Restoring earlier code does not undo saved Scene changes.
