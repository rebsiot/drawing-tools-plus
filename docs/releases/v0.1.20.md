# Drawing Tools+ v0.1.20 — Clearer name in Foundry (Beta)

## Improved
- **Foundry Module Manager now lists the module as “Drawing Tools+”** instead of “Drawing Quickbar,” matching its GitHub project name. This makes it easier to identify in the enabled/disabled module list.
- The floating in-world tool remains the Drawing Quickbar. Its version label now reads v0.1.20.

## Unchanged
- Existing module ID `foundry-drawing-quickbar`, manifest and settings keys, Drawing IDs, flags, Scene data, locks and player permissions.
- All drawing, styling, Locate and Multi-Delete functionality. No migration or automatic updates to world documents.

## Update and test
Back up the module folder and your world before upgrading. Update using the existing manifest or install the complete version-pinned ZIP, restart Foundry and refresh the browser. Open **Manage Modules** in a world and confirm **Drawing Tools+** appears as an entry with its normal enable/disable checkbox. Confirm the existing Quickbar still opens. Do **not** enable another copy under a different ID.

**Verification:** Automated/mock-tested and packaged; live Foundry v14 verification of this new module display name remains pending. The release is a **beta**, not a stable release.

**Rollback:** [v0.1.19 beta](https://github.com/rebsiot/drawing-tools-plus/releases/tag/v0.1.19) is the previous source/ZIP. Restoring code alone cannot undo unrelated Scene edits/deletions made during play.
