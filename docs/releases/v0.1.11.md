# Drawing Tools+ v0.1.11 — Player Drawings and Compact Editing

## New
- **Player Quickbar:** With Foundry's **Use Drawing Tools** permission enabled by the GM, players can draw, select, restyle, edit, duplicate and delete only their **own unlocked** Drawings. GM and other-player Drawings remain protected.
- **Compact tool row:** Select, Pen, Box, Circle, Polygon and Text fit on one row; Arrow is below.
- **Protected Drawing Info:** GMs can read details about a locked Drawing from the list without selecting or unlocking it.

## Fixed
- **Freehand Pen:** Drawings stay as **open strokes**, never a closed filled shape. Presets and color/width edits keep Pen paths unfilled.
- **Select vs. Unselect:** The lit Select button becomes **Unselect** when an object is selected. Click again to release it without deleting or changing it.
- **Less whitespace:** Line width, Fill opacity, and Text size controls are now closer together. The selected object list appears below its action buttons, not between them.

## Setup, safety and status
- **GM setup:** Game Settings → Configure Permissions → **Use Drawing Tools** → enable the chosen Player roles. The module does not change these permissions for you.
- Players cannot delete or edit GM drawings, locked grids, or other players' drawings through Quickbar controls. Foundry's native server permissions are authoritative.
- All Drawings remain native Scene Documents; no migration or mass import. **Back up your world before testing.**
- **Beta:** Automated tests and ZIP packaging passed. New behavior has **not been verified live in Foundry v14**.
