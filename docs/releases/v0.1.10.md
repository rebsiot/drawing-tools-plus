# Drawing Tools+ v0.1.10 — Quick First-Use Tutorial

## New
- **A short four-step guide:** When a GM opens the Quickbar for the first time, the walkthrough explains drawing tools, appearance, finding/locking map Drawings, and Arrow options.
- **Don't Show Again:** The last step has an opt-out saved to the current GM's Foundry User account, so it persists across future logins and browsers in the same world.
- **Tutorial link:** A small link at the bottom of the Quickbar reopens the guide anytime.

## Good to know
- **Not now** or Escape closes the guide for this login without opting out. It can return next session.
- The guide does **not** interrupt login. It appears only when an eligible GM opens Drawing Quickbar.
- It does not alter Scenes, Drawings, Tokens, or player permissions. Drawing Quickbar remains GM-only.
- **Beta:** Automated/mock tests and packaging passed; the modal and saved User flag still need a real Foundry v14 browser check.
