# Drawing Tools+ v0.1.13 — One Drawing List, Simpler Locks

## Improved
- **One inventory:** Removed the separate **Locked Drawings** panel. Every visible Drawing appears together under **All Drawings**.
- **Visible protection:** A small red lock symbol beside each protected Drawing's name replaces the repeated “Locked” text.
- **Quick filter:** **Locked only** sits beside the search label. Press it to see just locked Drawings; press again to restore the complete list. Text search and Show More continue working within the filtered results.
- **Same actions:** GMs still have Locate, Unlock, and read-only Info right on each locked row. Selecting several unlocked Drawings remains unchanged.

## Safety and testing
- No Scene/Token/Actor/Drawing data is changed by the filter. Locks, IDs, native ownership rules and player permissions are preserved; there is no migration.
- **Beta:** Automated tests and ZIP packaging were run in GitHub Actions, but the new UI is **not yet verified in a live Foundry v14 browser**.
- Back up the world before testing. [v0.1.12](https://github.com/rebsiot/drawing-tools-plus/releases/tag/v0.1.12) remains available to reinstall; reinstalling the module does not undo prior saved Scene edits.
