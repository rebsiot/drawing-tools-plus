# Drawing Tools+ v0.1.7 — Available from Token Controls

## New
- **Token Controls shortcut:** The Drawing Quickbar icon appears in **Tokens** as well as **Drawings**, using the same single toolbar.
- **No unwanted layer switch:** Opening the palette from Tokens keeps your Token controls active and your tokens selected. Choose Circle, Box, Pen, Polygon, Arrow or Text when you're ready to draw.

## Improved
- **All Drawings → Locate:** Find or highlight a Drawing while staying on Tokens.
- **Unlock:** Unlock a chosen Drawing without leaving the Token controls.
- **Select / Text:** When you explicitly select or edit a Drawing from the inventory, Foundry switches to its native Drawings layer.

## Good to know
- This is a convenience launcher, not a second drawing engine or another floating toolbar.
- GM-only; existing native Drawings, Tokens, lock states, preferences and module ID are unchanged.
- **Beta:** Automated/mock tests and ZIP packaging passed, but the new Token Controls behavior needs a real Foundry v14 client test.
- Back up your world before testing. [v0.1.6](https://github.com/rebsiot/drawing-tools-plus/releases/tag/v0.1.6) remains available for rollback.
