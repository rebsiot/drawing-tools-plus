# AFT Drawing Tools+ v0.1.21 (Beta) - Module list prefix

## Improved
- Foundry's **Manage Modules** screen now lists the add-on as **AFT Drawing Tools+** instead of **Drawing Tools+**.
- The floating toolbar is still called **Drawing Quickbar**.

Everything else is unchanged: the module ID `foundry-drawing-quickbar`, existing enabled state, settings, Scene Drawings, native lock and ownership protections, Locate, and Multi-Delete. There is no data migration.

## Updating
Back up the Foundry world and existing module folder, then update with the same Foundry manifest or install this version's complete ZIP. Restart Foundry and refresh your browser. In your world, open **Game Settings > Manage Modules** and look for **AFT Drawing Tools+**.

This is a beta release. The source and package have automated tests, but the renamed entry has not yet been verified in a live Foundry v14 session. If needed, restore the [v0.1.20 beta](https://github.com/rebsiot/drawing-tools-plus/releases/tag/v0.1.20) without changing the module ID. A code rollback does not restore drawings deleted during play.
