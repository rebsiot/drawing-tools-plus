# Drawing Tools+ v0.1.15 — An Easier-to-Recognize Launcher

## Improved
- **Better icon:** The Quickbar launcher in **Token Controls** now uses a **pen-and-ruler** symbol rather than another Palette icon.
- **Consistent:** The same pen-and-ruler icon is used in **Drawing Controls** and in the Quickbar header.
- **No workflow changes:** Both controls still open the same single floating Quickbar; opening from Tokens still preserves native Token controls and selection.

## Safety and testing
- Visual UI update only. No native Scene Drawing, Token, Actor, permissions, ownership, settings or module ID changes; no migrations.
- Automated regression tests and versioned ZIP packaging pass in GitHub Actions, but **the new icon's appearance has not been tested live in Foundry v14**.
- Back up your world before installing. [v0.1.14](https://github.com/rebsiot/drawing-tools-plus/releases/tag/v0.1.14) is the rollback version.
