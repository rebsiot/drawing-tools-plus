# Drawing Tools+ v0.1.5 - Draw, Then Edit

## New
- **Immediate selection:** New circles, rectangles, polygons and freehand shapes become selected for movement and resizing.
- **Direct styling:** A preset or style field affects one selected, unlocked Drawing immediately.
- **Safer multi-select:** Explicit Apply to N Selected; locked artwork is skipped.

## Fixed
- **Circle labels:** Edit Text makes a label visible on an existing ellipse or other Drawing even if it had no previous text.
- **Style workflow:** The quickbar explains whether controls affect the selected object or new-Drawing defaults.

## Good to know
- Outline, Danger, Highlight and Filled are built-in presets, not separate saved custom styles.
- Native Foundry Drawing documents and IDs are preserved.
- **Beta:** Automated tests passed; live Foundry v14 verification of these new interactions is still required.
- **Rollback:** Back up the world; v0.1.4 is retained at https://github.com/rebsiot/drawing-tools-plus/releases/tag/v0.1.4 .
