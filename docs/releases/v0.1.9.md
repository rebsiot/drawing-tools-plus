# Drawing Tools+ v0.1.9 — Delete Fix and Arrowhead Choices

## Fixed
- **Delete confirmation:** The error about `undefined (reading 'wait')` is fixed by calling Foundry v14's dialog method on its owning class. **Delete** still requires confirmation of one unlocked Drawing; Cancel and closing the dialog do not delete anything.
- **Cleaner Quickbar:** Arrow controls only appear when you choose **Arrow**. They disappear when you switch back to any other tool.

## New
- **Arrowhead shape:** Filled **Triangle** (default), **Diamond**, or **Chevron**.
- **Arrowhead position:** Start, End, Both, or No arrowheads, as before.
- The shape and position choices work together. The preview and the saved result both use a single native Foundry polygon Drawing.

## Good to know
- Existing arrows are not modified. New head-shape choices apply to arrows drawn after this update.
- The module ID remains `foundry-drawing-quickbar` and existing Scene data, gridlines and lock settings are preserved.
- **Beta:** Automated tests and ZIP checks run in GitHub Actions. The delete dialog and new arrow shapes still need a real Foundry v14 test.

Back up your world before testing destructive controls. [v0.1.8](https://github.com/rebsiot/drawing-tools-plus/releases/tag/v0.1.8) is retained for rollback, though installing an older module cannot restore deleted Scenes or Drawings.
