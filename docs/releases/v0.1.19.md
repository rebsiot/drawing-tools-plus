# Drawing Tools+ v0.1.19 - Full-size Locate highlights (Public Beta)

## Fixed
- **Locate now outlines the entire native Drawing**, not a maximum 360 x 260-pixel square around its center. This is especially noticeable on map-sized rectangles and hand-drawn scene borders.
- When a Drawing is too large for the current view, Locate pans to it and **zooms out to fit** when Foundry v14 permits it. Extremely large Drawings retain a centered name caption if Foundry's native minimum zoom prevents the entire border from fitting on screen.
- Rotated Drawings get a correctly rotated highlight frame. Small objects retain an easily visible minimum-size pulse. Panning, resizing or deleting an outlined Drawing updates or removes the temporary marker.

## Unchanged
- Locate remains a client-local HTML overlay, never a Scene Drawing modification or broadcast map ping.
- All Drawings inventory/search, GM-only locking and unlocking, player-owned Drawing permissions, Multi-Delete confirmation, quick styles, Token Controls, and the existing module ID and settings are preserved.
- No automatic changes to Drawing records, flags, IDs or map gridlines; no migration.

## Installation
1. Back up the Foundry world and `Z:\Data\modules\foundry-drawing-quickbar\` folder.
2. Update through the permanent Foundry manifest after it advances to v0.1.19, or stop Foundry and extract the complete versioned ZIP contents directly into the module folder (root-level `module.json`).
3. Restart Foundry, hard-refresh clients, verify v0.1.19 on the Quickbar.
4. In a disposable Scene, click Locate on a very large rectangle and verify its actual border; repeat for a small and rotated Drawing.

## Verification and rollback
Automated unit/source tests and complete ZIP packaging are recorded in `docs/TEST-REPORT.md`. **Live Foundry v14 test of the new Locate behavior is not yet completed.** Roll back to [v0.1.18](https://github.com/rebsiot/drawing-tools-plus/releases/tag/v0.1.18) if needed.
